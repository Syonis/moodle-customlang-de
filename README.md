# Moodle Custom Language Pack (de)

Dieses Repository enthält angepasste deutsche Moodle-Sprachdateien im Verzeichnis `customlang_de/`.
Ziel der Anpassungen ist es, die Texte an die traditionelle deutsche Rechtschreibung anzulehnen und das generische Maskulinum zu verwenden.

Die Anpassungen für die Moodle-App sind in [APP.md](APP.md) dokumentiert. Sie beschreiben die zehn benutzerdefinierten App-Texte und ihren Import in Moodle.

Die Datei `customlang_de.zip` wird als Release-Asset bereitgestellt und ist für den Import des Sprachpakets in Moodle vorgesehen.
