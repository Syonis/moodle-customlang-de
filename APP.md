# Moodle-App: angepasste Texte

In der Moodle-App können bis zu 10 Texte ohne Premium-Funktionen angepasst werden.

**Einstellung:** Mobile App → Premium-Funktionen → Nutzerdefinierte Texte
**String-Sammlung:** `tool_mobile | customlangstrings`

## Angepasste Texte

| String-ID | Deutscher Text |
|---|---|
| `core.login.onboardingimalearner` | Ich bin ein Schüler. |
| `core.login.onboardingimaneducator` | Ich bin ein Lehrer. |
| `core.user.participants` | Teilnehmer |
| `core.user.student` | Teilnehmer |
| `core.user.manager` | Manager |
| `core.user.editingteacher` | Trainer |
| `core.allparticipants` | Alle Teilnehmer |
| `core.user.useraccount` | Nutzerkonto |
| `core.user.userwithid` | Nutzer {{id}} |
| `core.teachers` | Trainer |
